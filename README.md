# Clash Royale AI Simulator — Android

Учебная автономная 2D-симуляция арены с простым табличным Q-learning. Это отдельная игра, не подключается к официальной Clash Royale и не управляет ею.

## Сборка APK через GitHub (без Android Studio и SDK на вашем ПК)

1. Создайте пустой репозиторий на GitHub с именем `ClashRoyaleAI`. Не добавляйте README, лицензию или .gitignore при создании.
2. Распакуйте этот ZIP на компьютере.
3. В репозитории нажмите **Add file → Upload files**.
4. Откройте распакованную папку `ClashRoyaleAI` и загрузите ВСЁ ЕЁ СОДЕРЖИМОЕ, включая скрытую папку `.github`. В Windows включите Проводник → Вид → Показать → Скрытые элементы.
5. Внизу нажмите **Commit changes**.
6. Откройте вкладку **Actions**. Workflow `Build Android APK` должен появиться автоматически.
7. Выберите его слева и нажмите **Run workflow → Run workflow**.
8. Дождитесь зелёной галочки. Откройте запуск, внизу найдите **Artifacts** и скачайте `ClashRoyaleAI-debug-apk`.
9. Распакуйте скачанный ZIP. Файл `app-debug.apk` — установщик приложения.

Если сборка упала: откройте красный job `Build debug APK`, нажмите шаг `Build APK`, скопируйте последние 20–30 строк ошибки и пришлите их в чат.

## Возможности прототипа
- 2D-арена, башни и юниты.
- Автоматический бой с простым противником.
- ИИ выбирает ожидание, ближнего бойца, стрелка или защиту.
- Упрощённое Q-learning обновляет оценки действий после каждого боя.
- Сохраняет число боёв, побед и решений на устройстве.

## Совместимость и ограничения
- Минимальная Android API: 23 (Android 6.0+); Huawei P20 подходит по версии Android.
- Это прототип с упрощённой симуляцией, а не полноценный Clash Royale AI.
- Не требует интернет-соединения во время игры.
- Не подключается к аккаунту или серверам Supercell.
